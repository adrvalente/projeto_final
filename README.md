# ScoutGest

Projeto Final do CET 25.0462 — aplicação de gestão dos elementos do Agrupamento de Escuteiros 676 Cristo-Rei e dos respetivos tutores.

## Versões

- **V1.0.0 — Estrutura inicial:** ficheiros base, modelo relacional, SQL e identidade gráfica.
- **V1.0.1 — CSS Integração:** folha de estilos centralizada, aplicação da paleta de cores, logótipo e favicon na página inicial, e adaptação a ecrãs pequenos.

## Executar localmente

Colocar a pasta do projeto em `htdocs` do XAMPP, iniciar o Apache e abrir `http://localhost/scoutgest/` (ajustar o endereço ao nome da pasta).

Nesta fase, a página inicial é demonstrativa; as restantes funcionalidades serão desenvolvidas em versões futuras.
